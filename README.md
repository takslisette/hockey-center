PROJEKTIN KUVAUS

Hockey Center on NHL-jääkiekkoon liittyvä verkkosovellus, joka näyttää ajankohtaisia tietoja NHL-joukkueista ja otteluista.

Sovellus on toteutettu osana Projekti 2a: AJAX-sovellus REST APIa hyödyntäen -koulutehtävää.

Sovelluksen tarkoituksena on harjoitella REST API käyttöä, AJAX-tiedonhakua ja verkkosivun sisällön päivittämistä JavaScriptillä.

SOVELLUKSEN OMINAISUUDET

NHL-joukkueiden näyttäminen joukkuekortteina

Joukkueiden hakeminen hakukentällä

NHL-otteluiden ja tulosten näyttäminen

NHL-sarjataulukon näyttäminen

Joukkueen valitseminen pudotusvalikosta

Valitun joukkueen otteluohjelman näyttäminen

KÄYTETYT TEKNIIKAT

HTML5 – sivun rakenne

CSS3 – ulkoasu ja responsiivisuus

JavaScript – sovelluksen toiminnallisuus

Fetch API / AJAX – tietojen hakeminen palvelimelta

NHL Web API – NHL-tietojen lähde

GitHub – lähdekoodin versionhallinta

Netlify – verkkosovelluksen julkaisu

Sovellus käyttää JavaScriptin fetch()-funktiota NHL-tietojen hakemiseen. Palvelimelta saatu JSON-data käsitellään JavaScriptillä ja näytetään verkkosivulla.

NHL API -pyynnöissä käytetään myös CORS-välityspalvelinta (proxy.cors.dev).

SOVELLUKSEN KÄYTTÖ

Avaa Hockey Center verkkoselaimessa.

Tarkastele NHL-otteluita ja sarjataulukkoa.

Hae haluamaasi NHL-joukkuetta hakukentällä.

Valitse joukkue pudotusvalikosta nähdäksesi sen otteluohjelman.

ITSEARVIOINTI

Projektin aikana opin käyttämään REST API ja hakemaan tietoja JavaScriptin fetch()-funktiolla. Harjoittelin JSON-datan käsittelyä, HTML-sisällön päivittämistä JavaScriptillä sekä tapahtumankuuntelijoiden käyttöä.

Opin myös toteuttamaan hakutoiminnon ja pudotusvalikon, joiden avulla käyttäjä voi vaikuttaa näytettäviin tietoihin.

Projektissa haastavinta oli API-tietojen hakeminen ja niiden esittäminen oikeassa muodossa. Ongelmia ratkaistessani opin lisää JavaScriptin toiminnasta ja virheiden selvittämisestä.

Olen tyytyväinen sovelluksen lopputulokseen, koska sen keskeiset ominaisuudet toimivat ja ulkoasu on selkeä.
